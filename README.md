# Atividade PySpark - Rocket Lab Dados 2026.2

Resolução dos exercícios de PySpark (joins, groupBy, withColumn/when e window functions).

## Como rodar
1. `pip install pyspark` (é necessário ter Java instalado)
2. Crie a pasta `data/` e coloque dentro: `fut_players_data.csv`, `metal_bands.csv`, `pokemon_data.csv`
3. `python atividade_pyspark.py` ou abra `RL_Dados_2026_2_Atividade_PySpark_resolvido.ipynb`
